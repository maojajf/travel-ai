# 旅游路线生成APP 产品后端服务

## 1、后端服务技术架构

- springboot 3.x
- mysql8.0
- redis4.x
- jdk21



## 2、功能模块项目划分

- 用户模块（预留）
- AI模块
- 内容模块（收藏，历史等）



## 3、要求

- 根据API返回的数据进行流式输出。使用 **SSE** 技术方式输出。
- 点击 **重新生成** ，再次调用API 进行数据的生成。



## 4、参考API

- 1、调用生成API接口

  ```
  import com.theokanning.openai.completion.chat.*;
  import com.theokanning.openai.service.OpenAiService;
  import java.util.List;
  
  OpenAiService service = new OpenAiService("sk-zF905NW7UCf5oC7ACG3d4m3quo1SuIEKJQH0vRIeLiOLf1rK",
      "https://api.ikuncode.cc/v1");
  
  ChatCompletionRequest request = ChatCompletionRequest.builder()
      .model("claude-sonnet-4-20250514")
      .messages(List.of(
          new ChatMessage("system", "你是一个经验丰富的全国各地旅游专家。"),
          new ChatMessage("user", "xxxx")
      ))
      .temperature(0.7)
      .maxTokens(1024)
      .build();
  
  ChatCompletionResult result = service.createChatCompletion(request);
  System.out.println(result.getChoices().get(0).getMessage().getContent());
  ```

  **响应接口使用流式输出**

  ```
  data: {"id":"chatcmpl-123","object":"chat.completion.chunk","choices":[{"index":0,"delta":{"role":"assistant","content":"你"},"finish_reason":null}]}
  
  data: {"id":"chatcmpl-123","object":"chat.completion.chunk","choices":[{"index":0,"delta":{"content":"好"},"finish_reason":null}]}
  
  data: [DONE]
  ```

  **定义角色**

  - system："你是一个经验丰富的全国各地旅游专家"
